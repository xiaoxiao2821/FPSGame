## DS 打包路线全记录(重要教训, 21:00-23:50)
- **需求**: 打 DS 包失败多轮后用户要求高效方案; 最终确认 win 包不能当 DS。
- **铁律(源码级确认)**: `CoreMisc.h::IsRunningDedicatedServer()`: `IsServerOnly()`(UE_SERVER, 仅 Server target) 返回 true; **`IsGameOnly()`(UE_GAME, Game target) 直接 return false** → **Game 目标二进制(FPS.exe)无论加什么参数永远无法进入 DS 模式**。实测 `-server -nullrhi -unattended` 仍加载 Lvl_Login + D3D12 渲染。
- **Launcher 版引擎打 DS 的完整死因链**:
  1. `InstalledBuild.txt` 存在 → UBT `InstalledPlatformInfo.IsValid(Server...)` 检查失败 → "Server targets are not currently supported from this engine distribution"。
  2. 改名 `InstalledBuild.txt` → UBT 认为源码版放行 Server target → 但**触发全量重编译引擎**(1093 个动作, 内存受限 2 并行 ≈2h)。
  3. Launcher 版 ThirdParty 源码被裁剪 → 5 个 C1083 缺失: `AHEasing/easing.h`, `SSEMathFun/sse_mathfun_extension.h`, `MiMalloc/static.c`, `msdfgen/msdfgen.h`(×2 文件) → BUILD FAILED。
  4. 结论: **Launcher 版引擎无法直接打 DS 包**, 除非补全 ThirdParty 源码(还有更多潜在缺失)或换源码版引擎。
- **关键参数经验**: `-NoCompile`(UAT 跳过脚本模块编译, 绕开 41 项目编译权限问题); `-nocompileuat`(RunUAT 用预编译 UAT); 二者可配合。但解决不了 Server target 根本限制。
- **状态**: `InstalledBuild.txt` 已恢复(改名 .bak 已还原); `FPSServer.Target.cs` 已创建(保留); 测试残留进程已清理。
- **替代方向**(待用户确认): ①编辑器 `UnrealEditor.exe FPS.uproject -server`(开发期 DS, 无需打包); ②Listen Server(局域网主机联机, Game 包支持); ③换源码版引擎出真 DS 部署包。

## Login 场景 UI 不显示 — 根因与修复 (01:17-01:34)
- **根因**: 登录 UI 创建放在 `AShooterLoginGameMode::BeginPlay()` —— **GameMode::BeginPlay 只在服务器进程执行**。PIE 联网模式(127.0.0.1:17777 多实例)下客户端 `Welcomed by server (Game: ShooterLoginGameMode)` 后, 客户端进程无 GameMode 逻辑, AddToViewport 从未在客户端跑过 → UI 不显示。
- **修复(用户方向)**: 登录场景是客户端入口, UI 由客户端 PC 创建, GameMode 只做配置。
  - 新增 `AShooterLoginPlayerController`(h/cpp): BeginPlay 中 `IsLocalController()` 判断后创建 BP_LoginMenu + AddToViewport(100) + UI 输入模式。默认 LoginMenuClass = BP_LoginMenu。
  - `AShooterLoginGameMode`: 构造函数设 `PlayerControllerClass = AShooterLoginPlayerController::StaticClass()`, **移除全部 UI 创建逻辑**(BeginPlay 及 LoginMenuClass/LoginMenuWidget 成员)。
- **编译**: UBT 编译 FPSEditor 成功(01:34, DLL 857KB)。编译前需删 `%LOCALAPPDATA%\UnrealBuildTool\Log.txt/Log.json`(杀软瞬时锁 → UnauthorizedAccessException)。
- **测试要点**: 编辑器需重启加载新 DLL; PIE 用 Standalone 或联网模式都应由客户端 PC 显示菜单。
